# MindSpark — Product Requirements Document

**Product:** MindSpark · Brain Arcade (web app)
**Built by:** [ShahNlabs](https://www.shahnlabs.com)
**Status:** v1.0 — playable, all 9 games shipped
**Last updated:** 2026-11-10

---

## 1. Overview

MindSpark is a collection of short brain-training mini-games in a dark neon style. It runs in any modern browser on phone, tablet and desktop. There's nothing to install, no account and no backend. You open `index.html` and play.

It combines two kinds of play:
- **Relaxing logic puzzles** that you solve at your own pace, with 100 levels each.
- **Fast reflex and memory challenges** where you chase a high score.

## 2. Goals

| Goal | How we measure it |
|---|---|
| Feel as polished as a native puzzle app | Smooth 60fps animations, sound and haptics on every action, no layout breaks from 320px phones to desktop |
| Quick to pick up | First-time tutorial with an animated demo for every game; a new player understands the goal within 30 seconds |
| Bring players back daily | Daily Pick, daily streak counter, stars and progress bars on every game |
| Zero setup | Plain HTML/CSS/JS, opens straight from a file, works offline (apart from web fonts) |

### Non-goals (v1)
- User accounts, cloud sync or leaderboards
- Ads, in-app purchases or analytics
- Multiplayer

## 3. Target users

- Casual players who want a 2–5 minute brain break on their phone
- People training memory, focus and mental math
- All ages. Text is short, colors are high-contrast and controls are big.

## 4. Platform & tech

| Area | Decision |
|---|---|
| Stack | Plain HTML + CSS + vanilla JavaScript (no build step, no framework) |
| Rendering | Canvas (Dot, One Stroke), SVG (Connect, Plumber tiles, icons), DOM + CSS transitions (Water Sort, Pattern, Quick Search, Left vs Right, Focus) |
| Storage | `localStorage`, key `mindspark.v1` |
| Audio | Generated live with the Web Audio API (no audio files) |
| Haptics | `navigator.vibrate` where the device supports it |
| Levels | Generated by code from a fixed seed per game and level, so level N is always the same puzzle and every puzzle is solvable |
| Fonts | Orbitron (headings) and Rajdhani (body) from Google Fonts, with system fallbacks |

## 5. App structure & screens

1. **Home**
   - Logo with the "by ShahNlabs" credit
   - Streak and total-stars pills, and a Settings button
   - Daily Pick card (one game picked each day from the date)
   - Grid of game cards, each showing level or best score and a progress bar
   - Footer credit "Built by ShahNlabs", which opens www.shahnlabs.com
2. **Game detail**
   - Large icon, stats, and a Start or Continue button
   - Full tutorial (animated demo, goal, steps, pro tips)
   - Level grid for level games (100 levels; locked or unlocked, with stars) or star goals for score games
3. **Play**
   - Back button, title and level, action buttons (Hint, Undo, Add tube, **?** Help, Restart)
   - Info chips (moves, time, score, lives…)
   - The game stage
4. **Result modal**
   - Animated 1–3 stars, confetti, and Next / Replay / Levels buttons
   - Score games show the score and a "NEW BEST!" badge instead
5. **Tutorial modal**
   - Opens automatically the first time you play each game, and again from **?**
   - For timed games, closing it restarts the game so the clock can't run out while you read
6. **Settings**
   - Sound and vibration on/off toggles
   - Reset progress (asks you to tap twice to confirm)
   - ShahNlabs credit

## 6. Games

### Level games (100 levels each; 1–3 stars per level; the next level unlocks when you clear one)

| Game | Mechanic | Difficulty curve | Stars | Assists |
|---|---|---|---|---|
| **Dot** | Drag lines between same-colored dots; lines can't cross; every cell must be filled | 5×5 grid with 4 colors, up to 9×9 with 9 colors | Based on moves vs. number of colors | 1 hint per level (reveals one correct line) |
| **Water Sort** | Tap a tube, then another, to pour; you may only pour onto the same color or into an empty tube | 3 colors, up to 12 colors (4 layers each, 2 empty tubes) | Based on moves; −1 if the extra tube was used | 5 undos; +1 extra tube once per level |
| **Plumber** | Tap tiles to rotate the pipes; water flows from the pump; every pipe must be connected with no open ends | 4×4, up to 8×9 | Taps compared with the minimum possible ("par") | 1 hint per level (fixes and locks one tile) |
| **Connect** | Link numbered planets horizontally or vertically (1 or 2 links per pair); links can't cross; all planets must form one network | 6 planets on 6×6, up to 18 planets on 10×12 | Based on solve time | 1 hint per level (fixes one link) |
| **One Stroke** | Trace every line exactly once without lifting your finger | 5 lines on 3×3, up to 20 lines on 5×5 | Based on resets | 1 hint per level (shows the start and draws the first third) |
| **Quick Search** | Tap floating bubbles in order: counting up, counting down, or random numbers smallest first | 7 bubbles, up to 30; speed rises with each level | Based on time vs. the target; wrong tap = +2 s | — |

### Score games (best score saved; stars from score thresholds)

| Game | Mechanic | Lives / time | Star goals |
|---|---|---|---|
| **Pattern** | Watch tiles light up in sequence, then repeat it; each round adds a step and the grid grows from 3×3 to 5×5 | 3 lives | 4 / 8 / 12 rounds |
| **Left vs Right** | Two tasks at once. Left: is the equation true? Right: does the ink color match the word (a Stroop test)? Each side has its own timer | 3 lives; gets faster as you score | 15 / 30 / 50 |
| **Focus & Multitask** | A 60-second mix of quick math, visual memory ("same as before?"), odd-one-out and flash counting; combo multiplier up to ×5 | 60 s; a mistake costs 3 s | 150 / 300 / 500 |

### Puzzle generation rules
- **Dot:** builds a random path through every cell of the grid, then cuts it into color segments, so a solution always exists.
- **Water Sort:** shuffles the colors, then a solver checks the puzzle can be solved before it's used.
- **Plumber:** grows a random tree of pipes from the pump, then scrambles the tile rotations.
- **Connect:** grows islands and bridges outward from one starting planet, so the bridges in the solution never cross.
- **One Stroke:** draws a random single-stroke walk with no crossing diagonals, so the walk itself is the solution.

## 7. UX requirements

- **Responsive layouts**
  - Phones (320–430px wide): portrait layout.
  - Phones turned sideways (landscape, height ≤ 540px): the controls move into a left sidebar so the puzzle gets the full height.
  - Tablets and desktop: wider grid. The app is capped at 1100px wide.
- **Touch first:** pointer events throughout, no scroll or zoom while playing, tap targets at least 38px, and notched-phone safe areas respected.
- **Feedback:** every action has a sound and an animation. Mistakes shake and play an error tone. Wins play a short jingle with confetti.
- **Accessibility:** high-contrast neon on dark backgrounds; animations are reduced when the device's "reduce motion" setting is on; keyboard shortcuts (Esc to go back; A/S/K/L in Left vs Right).
- **Guidance:** a tutorial for each game with an animated SVG demo, a goal, steps and tips. Hints are limited to one per level so they help without solving the puzzle.

## 9. SEO, discoverability & access

| Area | Implementation |
|---|---|
| Title / description | Keyword-focused title ("Free Brain Games Online…"); a ~155-character meta description naming all games |
| Headings | A single `<h1>` (the logo plus hidden "Free Brain Games Online" text), with h2/h3 in the content section |
| Visible content | A text section on Home (crawlable without JavaScript) covering what the app is, the 9 games with keywords, "Play anywhere" regions and an FAQ |
| Target regions | **India:** Delhi, Delhi NCR, Noida, Bengaluru, Hyderabad, Haryana, Yamuna Nagar · **Canada:** Alberta · **United Kingdom**. Covered by visible text, JSON-LD `areaServed` / `audience.geographicArea`, and `og:locale` en_IN + en_CA + en_GB |
| Structured data | JSON-LD `@graph`: `Organization` (ShahNlabs), `VideoGame` + `WebApplication` (free offer, genres, platforms), and `FAQPage` (FAQ rich results) |
| Social sharing | Open Graph and Twitter cards with a 1200×630 `og-image.png` |
| Canonical URL | Added by a small script from the live address, so it works on any domain |
| Crawling | `robots.txt` and `sitemap.xml` (**replace `YOUR-DOMAIN.com` after deploying**) |
| Installable / offline | `manifest.webmanifest`, PNG and maskable icons, apple-touch-icon, and `sw.js` (loads from the network first and falls back to the cache when offline) |
| Easy access | Each game has its own link (`/#water`, `/#dot`…), the page title changes per game, and a Share button uses the phone's share sheet or copies the link |
| Mobile and accessibility | Pinch-zoom allowed (helps accessibility and Lighthouse scores), double-tap zoom disabled with `touch-action: manipulation`, high contrast |

**Deliberately avoided:** hidden keyword stuffing and long lists of city names. Google treats these as spam. Regions appear once, naturally, in visible text and in structured data.

**After deploying:**
1. Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml`.
2. Add the site to Google Search Console (and Bing Webmaster Tools) and submit the sitemap.
3. To rank locally in a city, a ShahNlabs **Google Business Profile** and backlinks from local sites (Delhi, Noida, Bengaluru, Hyderabad, Haryana, Alberta, UK) matter more than anything on the page.
4. Test the page with Google's Rich Results Test and PageSpeed Insights.
